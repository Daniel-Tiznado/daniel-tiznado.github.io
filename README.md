##  Características técnicas

| Aspecto | Implementación |
|---------|---------------|
| **Diseño responsive** | Mobile-first con menús adaptativos (hamburguesa + bottom bar) |
| **Efectos visuales** | Partículas CSS, perspectiva 3D, máscaras dinámicas, gradientes animados |
| **Interacción** | Tarjetas flip, modales, acordeones, carruseles, juego de captura con cursor personalizado |
| **Gamificación** | Sistema de "cursos vistos" con progreso por categoría y recompensas |
| **SEO** | Schema.org (Person, ProfilePage, WebSite), Open Graph, Twitter Cards, canonical, sitemap |
| **Accesibilidad** | ARIA labels, roles semánticos, navegación por teclado |
| **Performance** | Preconnect a CDN, animaciones con `will-change`, imágenes optimizadas |

##  Propósito del portafolio

Este no es un currículum online. Es una **narrativa interactiva** que demuestra:

1. **Competencia técnica** — El código es el portafolio en sí mismo
2. **Pensamiento estratégico** — Cada sección cuenta una historia de evolución profesional
3. **Atención al detalle** — Desde el SEO técnico hasta la microinteracción del cursor

> *"La tecnología bien implementada solo tiene valor si resuelve problemas de negocio reales."*

---

##  SEO y datos estructurados

El sitio implementa **Schema.org** en múltiples formatos:

- `Person` — Datos personales, credenciales, empleo actual
- `ProfilePage` — Perfil profesional indexable
- `WebSite` — Estructura del sitio para motores de búsqueda
- `CollectionPage` — Para secciones de cursos y diplomados

Validado con:
- [Schema.org Validator](https://validator.schema.org/)
- [Google Rich Results Test](https://search.google.com/test/rich-results)
